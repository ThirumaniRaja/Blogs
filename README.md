# JS Interview Prep

A modern, responsive JavaScript Interview Questions & Practice Platform built with React, TypeScript, and Vite.

## Features

- Browse and search JavaScript interview questions with detailed explanations, code examples, and expected output
- Filter by difficulty (Easy / Medium / Hard) and category
- Take randomized multiple-choice quizzes with instant feedback
- Track completed questions, bookmarks, and quiz history (persisted in `localStorage`)

## Tech stack

React, TypeScript, Vite, React Router, Tailwind CSS, Lucide icons.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint
